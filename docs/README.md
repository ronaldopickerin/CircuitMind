# CircuitMind Documentation

This directory is the durable project knowledge base for CircuitMind.

## Structure

- `domain-model.md` — current electrical domain model and modelling principles.
- `roadmap.md` — high-level product and engineering direction.
- `ideas/` — useful concepts worth preserving before they become scheduled work.
- `decisions/` — architectural decisions and the reasoning behind them.

## Workflow

Use the repository rather than chat history as the long-term source of truth:

1. Capture promising but unscheduled concepts in `ideas/`.
2. Promote concrete implementation work into GitHub Issues.
3. Record important architectural choices in `decisions/`.
4. Update `roadmap.md` when priorities or milestone sequencing changes.
5. Keep implementation details, tests, and pull requests linked to the relevant issue.

Ideas are not commitments. They are preserved so they can be evaluated later without being lost.
