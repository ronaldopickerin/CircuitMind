# CircuitMind Ideas

This directory preserves useful product and engineering ideas that are not yet committed implementation work.

An idea belongs here when it is valuable enough to remember but is outside the current milestone or still needs design work.

When an idea becomes actionable:

1. refine its scope and acceptance criteria;
2. create a GitHub Issue;
3. link the issue back to the idea document if useful;
4. keep the idea document as design context or replace it with a formal decision record when appropriate.

Each idea should clearly state its status so exploratory concepts are not mistaken for implemented features.
